## En qué trabajo

**[MentorIA](https://mentoriaapp.cl)** es una plataforma de aprendizaje adaptativo de matemáticas para estudiantes universitarios en Chile. Combina:

- Un sistema de práctica que se adapta al nivel de cada estudiante.
- Un tutor socrático con IA que guía en vez de dar la respuesta.
- Una pizarra digital para resolver a mano.

Soy parte de un equipo de dos fundadores y lo hemos construido desde cero: producto, infraestructura y crecimiento.
